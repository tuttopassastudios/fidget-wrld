# Project rules

## Next.js 16 — critical breaking changes

Before writing any Next.js code, read the relevant doc in `node_modules/next/dist/docs/`. Key changes from training data:

### Async Request APIs (most common mistake)
`params`, `searchParams`, `cookies()`, `headers()`, and `draftMode()` are all **Promises** now. Synchronous access is fully removed.

```tsx
// WRONG — will crash at runtime
export default function Page({ params }: { params: { slug: string } }) {
  return <h1>{params.slug}</h1>
}

// CORRECT — await the promise
export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params
  return <h1>{slug}</h1>
}
```

Use `PageProps<'/path/[slug]'>` and `LayoutProps` type helpers (generated by `npx next typegen`).

### middleware → proxy
`middleware.ts` is deprecated. The file is now `proxy.ts` and the export is `proxy()`, not `middleware()`. Config flags renamed too: `skipMiddlewareUrlNormalize` → `skipProxyUrlNormalize`.

### Turbopack is default
`next dev` and `next build` use Turbopack by default. No `--turbopack` flag needed. Use `--webpack` to opt out.

### Caching APIs
- `unstable_cacheLife` → `cacheLife` (stable, no prefix)
- `unstable_cacheTag` → `cacheTag` (stable, no prefix)
- New: `updateTag()` for read-your-writes semantics
- New: `refresh()` from `next/cache`
- `revalidateTag()` accepts optional `cacheLife` profile as second arg

### Parallel routes
All parallel route slots require explicit `default.js` files. Builds fail without them.

### Removals
- AMP support removed entirely
- `next lint` removed — use ESLint directly
- `serverRuntimeConfig` / `publicRuntimeConfig` removed — use env vars
- `next/legacy/image` deprecated — use `next/image`
- `images.domains` deprecated — use `images.remotePatterns`
- `experimental.dynamicIO` → `cacheComponents`
- `experimental.ppr` removed → use `cacheComponents`

### React 19.2
App Router uses React 19.2. New APIs: `ViewTransition`, `useEffectEvent`, `Activity`. React Compiler support is stable via `reactCompiler: true` in config.

## Project stack
- Next.js 16.2.1, React 19.2, TypeScript
- App Router with route groups: `(storefront)` → `(shop)` for cart/checkout/products; `(dashboard)` for admin
- Local storage for cart/wishlist/promo state; local product catalog in `data/products.ts`
- Stripe for payment processing
- Motion library for scroll animations; CSS view transitions enabled
- Deployed on Vercel Hobby (free) plan — 10s function timeout, 100GB bandwidth
- CSS: globals.css + design-system.css + sidebar-menu.css + dock.css + CSS modules
